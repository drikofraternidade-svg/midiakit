# Fraternidade E23 — Mídia Kit

Site estático pronto para GitHub Pages.

## Publicar
1. Crie/abra um repositório no GitHub.
2. Envie `index.html`, `style.css` e `script.js` para a raiz.
3. Em **Settings → Pages**, escolha **Deploy from a branch** e selecione `main` / `/root`.
4. Salve e aguarde o endereço do GitHub Pages.

## Personalização
- Métricas: `script.js`
- Textos e contato: `index.html`
- Cores/layout: `style.css`

A primeira versão usa elementos gráficos em CSS e não depende de imagens externas.
